# Security Policy

## Supported versions

Security fixes are prioritized for the latest release line.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
[private security advisory form](https://github.com/r4khul/pinshot/security/advisories/new)
so the report can be reviewed privately.

Include the affected version, reproduction steps, impact, and any proof of
concept that helps confirm the issue. Please allow time for validation before
sharing details publicly.

Once a report is confirmed, maintainers will coordinate a fix and disclosure
plan with the reporter. Do not include passwords, tokens, personal data, or
other secrets in a report.
