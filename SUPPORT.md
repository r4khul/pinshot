# Support

## Before asking for help

- Check the README and existing issues for known behavior and workarounds.
- Confirm that you are using a supported Android version and the latest release.
- Include the app version, Android version, device or emulator model, and clear
  reproduction steps.

## Where to ask

- For reproducible bugs, [open a bug report](https://github.com/r4khul/pinshot/issues/new/choose).
- For questions and usage help, use [GitHub Discussions](https://github.com/r4khul/pinshot/discussions) when available.
- For security concerns, follow the [security policy](SECURITY.md) instead of
  opening a public issue.

Please avoid posting personal information, private screenshots, access tokens,
or other sensitive data in public support requests.
